# Image Processing Project using OpenCV

## Overview

This project implements various image processing techniques using Python and OpenCV (`cv2`). It provides functionalities for reading, manipulating, analyzing, and enhancing images through different computer vision operations.

The project explores fundamental image processing concepts such as image transformation, filtering, edge detection, color space conversion, and image enhancement.

## Features

- Image loading and displaying
- Image resizing and scaling
- Image cropping
- Color space conversion (RGB, Grayscale, HSV)
- Image thresholding
- Noise reduction and smoothing
- Image sharpening
- Image rotation and flipping

## Technologies Used

- **Python** – Programming language
- **OpenCV (`cv2`)** – Image processing and computer vision
- **NumPy** – Numerical operations on image arrays

## 🖼️ Image Processing Operations

### Grayscale Conversion

Converts a colored image into grayscale by removing color information while preserving intensity values.

### Image Resizing

Changes the dimensions of an image while maintaining or adjusting its aspect ratio.

### Image Blurring

Applies smoothing filters to reduce noise and unwanted details.

### Edge Detection

Identifies boundaries and significant changes in image intensity using the Canny edge detection algorithm.

### Thresholding

Separates objects from the background by converting pixel intensities into binary values based on a threshold.

### Image Transformation

Performs operations such as rotation, flipping, cropping, and scaling.
